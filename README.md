# Yury Shirokov — Personal Website

Personal portfolio site for Yury Shirokov, built with React and Vite.

Live site: https://yuryshirokov.vercel.app/

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run check
```

`check` builds the site, prerenders crawlable content into `dist/index.html`, and verifies the required public assets are present.

## Stack

- React 18
- Vite
- Vercel Analytics
- Formspree for the contact form
